# Phase 1 — Project Scaffolding

## Goal
Set up the complete repository skeleton: all directories, base configuration files, CLAUDE.md, and README.md. Nothing is generated by agents yet — this phase creates the empty but correctly structured foundation that every subsequent phase builds on.

---

## Prerequisites
- Claude Code CLI installed and authenticated
- Git installed
- Working directory: the project root
- GitHub account/remote available and `gh` CLI installed (the PR agent needs `gh auth status` to pass)

---

## Step-by-Step Instructions

### Step 1.1 — Initialize Git Repository
```bash
git init
git branch -M main
```
Expected result: `.git/` folder created, on `main` branch.

---

### Step 1.2 — Create Directory Tree
Create the following directories (all empty at this stage):

```
.claude/
.claude/agents/
.claude/skills/            (each skill is <name>/SKILL.md)
.claude/hooks/
docs/
user-stories/
src/
tests/
tests/unit/
tests/integration/
tests/fixtures/
output/
output/reports/
output/test-results/
plan/
```

Each empty directory needs a `.gitkeep` file so git tracks it:
- `.claude/hooks/.gitkeep`
- `docs/.gitkeep`
- `user-stories/.gitkeep`
- `src/.gitkeep`
- `tests/unit/.gitkeep`
- `tests/integration/.gitkeep`
- `tests/fixtures/.gitkeep`
- `output/reports/.gitkeep`
- `output/test-results/.gitkeep`

---

### Step 1.3 — Create `.gitignore`
Standard Python gitignore covering:
- `__pycache__/`, `*.pyc`, `*.pyo`, `*.pyd`
- `.env`, `.venv`, `venv/`, `env/`
- `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`
- `dist/`, `build/`, `*.egg-info/`
- `output/` (generated artifacts, not versioned)
- `.DS_Store`, `Thumbs.db`

---

### Step 1.4 — Create `pyproject.toml`
Minimal project metadata:
```toml
[project]
name = "agentic-sdlc-pipeline"
version = "0.1.0"
description = "Agentic SDLC pipeline driven by Claude Code"
requires-python = ">=3.11"

[tool.pytest.ini_options]
testpaths = ["tests"]

[tool.ruff]
line-length = 88
```

No runtime dependencies yet — implementation agent will add them during the Phase 6 run.

---

### Step 1.5 — Create `CLAUDE.md`
This file is loaded automatically by Claude Code into every session in this directory. It must explain:

**Sections to include:**
1. **Project Overview** — one paragraph on what this pipeline is and why it exists
2. **How to Run the Pipeline** — exact invocation (orchestrator must be the main-thread agent; subagents cannot spawn subagents):
   ```
   claude --agent orchestrator
   > process user-stories/<filename>.md [--fresh]
   ```
3. **Pipeline Phases** — brief description of each of the 9 steps in order (requirements, architecture, design review, impl planning, implementation, code review, verification, doc sync, PR)
4. **Interaction Levels** — explain L1 (interactive), L2 (run+approve), L3 (explicit approve)
5. **File Conventions** — where artifacts live, naming rules for user story files
6. **Do Not** section — list things Claude should never do (invoke subagents directly, skip gating checks, create the PR without user confirmation)

---

### Step 1.6 — Create `README.md`
User-facing documentation. Sections:
1. **What This Is** — 2-3 sentence overview
2. **Quick Start** — 4-step guide: clone, add user story, invoke orchestrator, follow prompts
3. **Pipeline Architecture** — ASCII diagram of the flow
4. **Folder Structure** — annotated tree
5. **Agent Reference** — table of all 9 agents with their role and interaction level
6. **Requirements** — Claude Code version, Python version
7. **Contributing** — how to add a new agent or skill

---

### Step 1.7 — Create `docs/changelog.md`
Initialize with a header only. The orchestrator appends a new entry here after each agent run:
```markdown
# Pipeline Changelog

<!-- Entries appended automatically by the orchestrator after each agent run -->
```

---

### Step 1.8 — Initial Commit
Stage and commit everything:
```bash
git add .
git commit -m "chore: scaffold project structure for agentic SDLC pipeline"
```
